Before you fly

System requirements.

These are the currently listed requirements. Actual performance can vary with aircraft, terrain and settings.

🖥️ Windows PC

  • Windows 10 or Windows 11, 64-bit
  • 4 GB RAM minimum
  • 8 GB RAM recommended
  • GPU supporting WebGL / compatible graphics
  • Approximately 250 MB storage

📱 Android

  • Android 7.0 or newer
  • Compatible Android device
  • Approximately 50 MB storage
  • Performance varies by device
  • Allow APK installation only when appropriate

About the project

Created by After Redemption.

ARS Flight Simulator is an independent flight simulation project developed under the After Redemption name. The goal is to make aviation simulation accessible on Windows and Android.

ARS Flight Simulator is an independent project and is not an official Microsoft Flight Simulator, Airbus or Boeing product.
